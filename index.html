Exp. 01shipped

One Security Scanner for All Code

How do you add a new language to Vanir without writing a parser from scratch?

Worked for Google's Android Security team, as part of my UW iSchool capstone, on Vanir: Google's open-source scanner that reads source code to find security patches that never made it in. It only understood C/C++ and Java, and every new language meant weeks of hand-writing a fragile parser from scratch.

problem
each language needed its own hand-built grammar: weeks of work, unreliable community versions, nothing reusable for the next one
solution
I plugged in tree-sitter, the parser behind GitHub and Neovim, through one shared layer. Python is now a pip install; any new language is three short methods
proof
caught a critical (CVSS 9.0) unpatched vulnerability in a real Python project, and parsed Django, Ansible and Scrapy, 5,000+ files, with zero errors

What Refusal Looks Like Inside Qwen

When Qwen refuses very different harmful requests, is it thinking the same thing each time?

I ran Anthropic's Jacobian lens over Qwen3.6-27B at the moment it refuses, using Transluce's WeirdChat transcripts. Self-harm, drunk driving and lasers at aircraft all light up the same hidden words around layers 37–47 (unsafe, prohibited, and oddly, cybersecurity). A plain logit lens misses them entirely.

Exp. 04done

Why Claude Says No to Safety Research

When Claude Opus 4.5 refuses a safety-research task, is it objecting to the work, or unsure the request is legitimate?

I extended Singh's safety-refusals experiment. Adding one line saying Trust & Safety had signed off took refusals from 80% to 0% over 50 runs, with the task itself unchanged. The reasons the model gives for refusing don't predict what changes its mind.
